# CPK_KeyRemap_APK
Clicks Power Keyboard のキー割り当てを変更するAPKを配布するリポジトリです。
  
  
## APKのインストールで変更されるキー
### 「ExKeyMo Keyboard Layout.apk」　※楽天ミニ（C330）、moto g7、F(x)tec Pro1-X 等で動作
・Android 9以降なら、まずはこれを使ってみてください。  
・Ctrlキー：有効化（Clicks設定アプリがなくても有効化されるようにします）  
・Clicksキー：全角／半角切り替えに割り当て  
・丸４つキー：カーソル左  
・丸６つキー：カーソル右  
・マイクキー：Shift  
　
### 「A8K_ExKeyMo Keyboard Layout.apk」　※Android 8.x系で動作
・Clicksキー：全角／半角切り替えに割り当て  
・丸４つキー：カーソル左  
・丸６つキー：カーソル右   
・マイクキー：Ctrl  
・Ctrlキーは色々戦いましたが、頑なに効いてくれませんでした。  
　
### 「M50s_ExKeyMo Keyboard Layout.apk」　※Moto edge50s PRO 向け
・楽天ミニ（C330）等向けと同じキーリマップです。  
・Clicks設定アプリで、Additional Settings を「Alt」にしてご使用ください。  
　
  
## インストール方法
１）APKをダウンロード  
２）ファイルアプリを開き、apkファイルをタップ  
３）Google Playからのアプリスキャン要求のウィンドウが表示された場合は、スキャン後にインストール  
  
  
## インストール後の作業
１）Clicks Power Keyboard に接続  
２）設定 ＞ システム ＞ 言語と入力 ＞ 物理キーボード ＞ Clicks Power Keyboard の表示をタップ ＞ キーボードレイアウトの設定 ＞ ExKeyMo Layout のみを選択  
３）画面を戻して、Clicks Power Keyboard のデフォルトレイアウトが「ExKeyMo Layout」になっていることを確認  
４）スマホを再起動  
  
【注１】スマホを再起動しないと設定が反映されないので、必ず再起動を行ってください！！  
【注２】手順２～３は、端末によって若干メニューや辿り方が違う場合もあるので、雰囲気でその辺掴んでくださいｗ
